How it works technically:

Capabilities

  • OpenAI-Compatible: Most 3rd parties (Groq, OpenRouter) and Local tools (Ollama) use the OpenAI chat completions format.
  • CORS Bypass: Localhost calls usually bypass CORS; for 3rd party APIs, we'll use a standard header approach.
  • Total Privacy: Keys never hit a server; they stay in localStorage.

Caveats

  • CORS Restrictions: Some APIs (like Anthropic) strictly block browser calls. We may need a tiny "Edge Proxy" or advise users to use an OpenAI-compatible bridge.
