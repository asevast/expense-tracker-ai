Production Plan: PWA + AI

Choosing the right architecture for an "ASAP" deployment

A

Bring Your Own Key (BYOK)

Users provide their own Anthropic/OpenAI API key. Key is stored locally in the browser.

  • Privacy: Highest. No data ever leaves the device except to the AI provider.
  • Cost: Zero for you. Users pay for their own usage.
  • Speed: Fastest to deploy (no backend setup).
B

Edge Functions (Managed)

Small proxy functions (Vercel/Netlify) handle AI calls and hide your master API key.

  • UX: Seamless. Users don't need to know about API keys.
  • Cost: You pay for the AI tokens. Requires usage limits/auth to prevent abuse.
  • Setup: Slightly more complex (deployment secrets, routing).

Plus: Standard PWA Features

Manifest & Icons

Make the app installable on iOS/Android home screens.

Offline Support

Basic service worker to ensure the app loads without internet.

Web Share Target

Allows sharing receipt images or text directly to the app.
