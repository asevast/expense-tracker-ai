Implementation Details

Smart Logic

  • Contextual Prompts: We'll send the list of existing CATEGORIES to the AI to ensure it picks a valid one.
  • Privacy-First Insights: Data is summarized locally before being sent to the LLM (e.g., "Food: $500, 10 transactions" instead of sending every single line item).

Handling Failures

  • Graceful Degradation: If the AI key is missing or the provider is down, the app works perfectly as a standard manual tracker.
  • Debounced Calls: Categorization only fires after the user stops typing to save tokens.
