Implementation Strategy: "i18n-lite"

Approach

  • LanguageContext: Store current locale ('en' or 'ru') in a new context, persisted to localStorage.
  • Translation Map: A simple dictionary { en: { hello: 'Hello' }, ru: { hello: 'Привет' } }.
  • Formatting: Update formatCurrency and formatDate to respect the active language automatically.

Scope

  • Static UI: All buttons, labels, and titles will be translated.
  • Dynamic Content: AI insights and category suggestions will be requested in the user's active language.
  • Categories: We can provide translated labels for the CATEGORIES constants.
